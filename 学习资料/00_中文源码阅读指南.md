# SP²RINT 中文源码阅读指南

本目录是基于上游 ScopeX-ASU/SP2RINT 的学习注释版。原始算法语句、变量、默认参数和调用流程不作修改；中文注释用于解释模块职责、函数用途和阅读重点。

## 建议学习顺序

1. `projected_classification.py`：先看 main、train、project_to_implementable_subspace，建立训练—物理投影—校准的整体流程。
2. `core/models/layers/meta_conv1d_ete.py`：理解 DONN 光学层的传输矩阵参数、W_buffer、前向传播。
3. `core/models/patch_metalens.py`：理解 Patch 划分、局部电磁求解、响应矩阵拼接和结构参数更新。
4. `core/utils.py`：理解传输矩阵匹配损失、相位/振幅损失和优化器调度。
5. `thirdparty/MAPS_old/core/fdfd/`：理解 FDFD 离散 Maxwell 方程、线性求解、导数与近远场。
6. `thirdparty/MAPS_old/core/invdes/`：理解 level-set 参数化、器件目标函数和伴随逆向设计。
7. `thirdparty/MAPS_old/thirdparty/ceviche/`：追踪 FDFD 与伴随导数的底层实现。

## 代码与物理概念对照

| 物理/算法概念 | 主要代码位置 |
|---|---|
| DONN 理想复传输矩阵 | core/models/layers/meta_conv1d_ete.py |
| 目标矩阵提取与投影调度 | projected_classification.py |
| Patch 电磁仿真与 TM 拼接 | core/models/patch_metalens.py |
| 传输矩阵损失 | core/utils.py |
| FDFD Maxwell 离散 | thirdparty/MAPS_old/core/fdfd/ |
| Level-set 结构表示 | thirdparty/MAPS_old/core/invdes/models/layers/parametrization/levelset.py |
| 伴随梯度/Jacobian | thirdparty/MAPS_old/thirdparty/ceviche/jacobians.py |
| 近场到远场 | core/near2far.py 与 MAPS FDFD near2far.py |

## 重要提醒

- 这份注释版不是新的算法实现，也不代表所有配置都能在 Windows 原生环境运行。
- MAPS/Ceviche 属于仓库内第三方依赖；本版仅对关键物理求解文件补充阅读注释。
- 论文中的公式、源码中的变量和实际配置必须逐项对应，不能把教学伪代码当作源码。
- 运行前先检查 README、配置文件、数据路径、求解器依赖及 GPU/CPU 后端。
