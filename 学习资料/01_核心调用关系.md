# SP²RINT 核心调用关系

## 主流程

`projected_classification.py`
→ 构建 DONN 模型和数据
→ 训练理想化传输矩阵与数字网络
→ 定期调用 `project_to_implementable_subspace()`
→ 读取每层目标响应
→ `PatchMetalens` 初始化/更新结构变量
→ 局部 Patch 电磁仿真
→ 拼接实际复传输矩阵
→ 计算匹配损失
→ MAPS/Ceviche 物理梯度与结构优化
→ 将物理响应反馈给 DONN
→ 多层系统校准与评估。

## 重点对象

- `W_buffer`：光学层当前前向使用的传输矩阵缓存；不是几何宽度，也不是 Maxwell 系数矩阵。
- `PatchMetalens.weights`：物理逆向设计中的结构参数化变量；应结合 MAPS level-set 实现判断其具体表示。
- `stitched_response`：由多个局部仿真结果按输入/输出采样索引拼接得到的复响应矩阵。
- `target_response`：DONN 当前希望实现的目标矩阵。
- `loss.backward()`：对当前可微计算图回传梯度；物理求解器如何提供导数，需要继续追踪 MAPS/Ceviche 的求解和伴随实现，不能简单认为普通 PyTorch 自动微分穿过所有 Maxwell 求解步骤。

## 阅读源码时必须记录

1. 输入和输出的 shape。
2. 复数 dtype（complex64/complex128）。
3. 长度单位（m、μm、nm）及频率/波长定义。
4. 激励模式、传播方向、边界条件和监测面。
5. 目标矩阵与物理响应是否经过相同归一化。
6. 梯度具体对哪个变量求导。
