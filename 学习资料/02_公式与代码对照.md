# SP²RINT 公式与代码对照

## 1. DONN 复传输矩阵

在 default 参数化模式下，光学层传输响应可由振幅与相位表示：

[
\mathbf W=\mathbf A\odot\exp(i\mathbf\Phi).
]

对应阅读：`core/models/layers/meta_conv1d_ete.py` 中传输矩阵生成、缓存和 forward 逻辑。注意不同 TM_model_method 可能有不同实现。

## 2. 目标矩阵与物理响应

- 目标响应：DONN 训练得到的矩阵。
- 物理响应：由当前几何结构经电磁求解获得的矩阵。
- 投影的目标是使物理响应在所选损失定义下接近目标响应。

常见形式：

[
\mathcal L_{TM}=\mathcal L_{amp}+\mathcal L_{phase}.
]

具体振幅、相位权重、相位包裹处理和归一化，以 `core/utils.py` 中实际损失实现为准。

## 3. FDFD

频域 Maxwell 方程离散后通常写成稀疏线性系统：

[
\mathbf A(\varepsilon)\mathbf x=\mathbf b.
]

其中矩阵与介电常数分布、网格、频率、边界条件有关；右端项代表源激励。请在 MAPS FDFD 实现中确认具体场变量与符号约定。

## 4. 伴随梯度

对目标函数 `L(x, ε)`，伴随方法通过正向场和伴随场计算介电参数梯度，避免对每个设计变量逐一有限差分。具体符号、共轭、归一化和离散索引必须以源码实现为准。

## 5. Patch 拼接

局部 Patch 计算提供局部输入到输出的复场响应，再按全局输入列和输出行索引累积/拼接。检查边缘 Patch、重叠区域、采样率及响应归一化，避免重复计数或索引偏移。
